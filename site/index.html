//! 一只爱啃代码的狗
use dg_core::Document;
use dg_syntax::Highlighter;

fn main() -> Result<(), Error> {
    let mut doc = Document::open("welcome.rs")?;
    let syntax = Highlighter::for_language("rust");
    doc.wrap(Smart);

    loop {
        match app.next_event()? {
            Event::Insert(text) => doc.insert(&text),
            Event::Save => doc.save()?, // 原编码落盘
            _ => {}
        }
    }
}

FEATURES

够快，也够能折腾

从消息循环到字形绘制都在本机完成；每个能力都由对应的 crate 负责，装不装、改不改都随你。

原生，不套壳

窗口、菜单、滚动条交给系统原生 API，正文由系统文字渲染引擎绘制。没有 Electron，也没有内嵌浏览器；将来换平台时，编辑器主体不用重写。

增量高亮

tree-sitter 驱动的语法着色，改哪里只重算哪里；语法解析器做成插件包，用什么装什么。

LSP 内置

补全、诊断、跳转接标准 Language Server，位置换算精确到行内字符，不用再挂一层壳。

打得开大文件

行索引按需建立，大文件也能随手翻；十六进制视图单有一套模型，改字节不会撑爆界面。

主题与字形

27 套配色，深色浅色都有。粗细、斜体、下划线、删除线、点线、波浪线在主题表里逐项可调。

Lua 5.4 脚本

内置脚本引擎，写皮肤、加命令、往工具栏和停靠区放面板，不用重新编译。

停靠面板

查找结果、输出、书签、大纲与文件树都是可停靠面板，按标签页切换。

编码与换行

UTF-8、UTF-16、ANSI 自动识别，CRLF 与 LF 原样保留；保存时按原编码写回，不乱改字节。

THEMES

二十七套配色，现场换

点一下主题名，下面的窗口立刻换色。颜色全部读自随程序发布的主题文件。

/// 文档模型：rope 正文 + 行缓存
pub struct Document {
    pub path: PathBuf,
    pub encoding: Encoding,
    history: Vec<Revision>,
}

impl Document {
    /// 保存时保留原来的编码与换行。
    pub fn save(&mut self) -> io::Result<()> {
        let bytes = self.encode(); // UTF-8 / UTF-16 / ANSI
        std::fs::write(&self.path, bytes)?;
        self.dirty = false;
        Ok(())
    }
}

ARCHITECTURE

十个 crate，一只编辑器

外壳负责把系统事件接到核心上；文档、排版、语法、LSP、渲染、脚本各占一个 crate。哪一层想换都能单独动，测试也按 crate 分开跑。核心不绑窗口系统：目前接的是 Windows 外壳，将来 Linux 与 macOS 只需再接一层外壳，编辑器主体不用改。

dg-app 把各层拼起来；核心 dg-core 不知道窗口存在。

dg-app平台外壳：框架、对话框、输入、停靠、工具栏
dg-core文档存储：rope、行缓存、选区、撤销、折叠、查找
dg-layout文本度量、换行引擎、纵向行索引
dg-syntaxtree-sitter 注册表、增量高亮、折叠跨度
dg-lspLSP 客户端、rope 与 LSP 位置换算
dg-render绘制管线、主题、小地图、标尺
dg-ui状态栏模型、菜单、滚动条、面板
dg-hex十六进制视图模型
dg-large大文件行索引
dg-scriptLua 脚本与脚本包

GET STARTED

把狗牵回家

下载发行版，或者直接拿源码跑。构建只依赖 Rust 工具链，没有 Node、没有额外 SDK。当前提供 Windows 版本；核心与窗口系统解耦，Linux 与 macOS 是后续的目标平台。

  • Rust 1.85+（edition 2024）
  • Windows 10 / 11（当前版本）
  • cargo build --workspace 之后即可运行
